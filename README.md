# NovaCart — Production Capstone Project

## Task 06: Production Capstone Project & Live Deployment

NovaCart is a responsive production-style catalog web application created for a Full Stack Web Development capstone.

### Implemented requirements

- Authentication simulation with demo login
- Interactive product catalog
- Create, Read, Update and Delete (CRUD) operations
- Search and category filtering
- Persistent state using browser `localStorage`
- Responsive mobile/desktop UI
- Professional README and architecture documentation
- Deployment-ready static web application

### Demo login

- Email: `demo@example.com`
- Password: `123456`

### Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage API
- Git / GitHub
- Vercel, Netlify or Cloudflare Pages for deployment

## Run locally

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Use the demo credentials.
4. Add, edit and delete products.
5. Refresh the page to verify persistent state.

For a production deployment, upload the project to GitHub and import the repository into Vercel/Netlify/Cloudflare Pages.

## GitHub submission

Create a public GitHub repository and upload all project files.

## Live deployment

Deploy the repository using a public cloud platform. The final submission should contain:

1. GitHub source-code repository URL
2. Live deployed website URL

## Feature highlights

### Authentication
A simulated login flow protects the main dashboard. The session is persisted in LocalStorage.

### CRUD
Users can create, view, update and delete catalog products.

### Persistent state
Product changes remain after browser refresh through LocalStorage.

### Responsive design
The interface adapts to mobile, tablet and desktop screens.

## Security note

This capstone uses client-side authentication simulation only. It is suitable for demonstrating front-end/full-stack workflow concepts, but real production authentication should use a secure backend, hashed passwords, HTTPS and server-side authorization.
